Everything You Need

Secure Authentication

Register and log in with JWT-powered authentication. Your data stays private and protected.

Income & Expense Tracking

Add, edit, and delete budget entries. Categorize every transaction as income or expense with custom categories.

Personal Dashboard

View total income, expenses, and net balance at a glance with category breakdowns and recent transactions.

REST API Powered

Built on a robust Express + MongoDB REST API. Integrate with any frontend, mobile app, or tool you like.

Custom Categories

Organize your budget with custom categories like Food, Rent, Salary, Freelance — whatever fits your life.

Token-Based Sessions

No cookies needed. Your session token lives safely in localStorage and is sent as a Bearer token with every request.

API Endpoints

All protected routes require a Bearer <token> header.

Method Endpoint Description Auth
POST/api/v1/auth/registerCreate a new accountNo
POST/api/v1/auth/loginLog in & get JWT tokenNo
GET/api/v1/auth/profileGet current user profileYes
GET/api/v1/budgetsList all budget entriesYes
POST/api/v1/budgetsCreate a budget entryYes
PUT/api/v1/budgets/:idUpdate a budget entryYes
DELETE/api/v1/budgets/:idDelete a budget entryYes
